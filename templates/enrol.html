These were eleven `{{ ... }}` interpolations inside the script itself, which is the construction that makes US-5 possible: a value rendered into a JavaScript string literal is a value that can end the literal early. ⚠️ **`data-record` is single-quoted, and that is load-bearing.** This comment used to end "an attribute value needs no guarding at all", which is false and cost the enrolment page entirely. `tojson` escapes `<`, `>`, `&` and `'` - it does NOT escape `"`, because it is built to be safe inside a script element or a *single*-quoted attribute. In a double-quoted one the first `"` of the JSON closes the attribute, so `getAttribute("data-record")` returned the single character `{`, `JSON.parse` threw at enrol.js line 34, and the whole IIFE died before reaching `openCamera(null)` on its last line. The page then sat on every placeholder the server had rendered - "Preparing the camera...", "Waiting for camera permission..." - with no error anywhere, because the failure was in the browser and the log is on the server. It only bit *new* enrolments: recapture passes `record = {}`, which contains no quote. Add Student passes four keys and never opened a camera. US-5 is the same lesson one context over, and the guard is the same one: a value that carries data belongs in an attribute *value*, quoted so that nothing in it can be read as markup. `tests/test_templates.py` parses this rather than grepping it - the prose above contains the string it would search for (lessons.md L12). #}
